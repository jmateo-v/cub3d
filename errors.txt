1. MAPS ONLY NAMED '.CUB' ARE ACCEPTED, THIS IS LIKELY WRONG BUT IDK, EASY TO FIX.

2. THERE'S PROBLEM WITH THE WIDTH OF THE MAP LINES, WHEN RENDERING, IF A LINE IS
SHORTER THAN THE LONGEST LINE OF THE MAP, THERE'S A CHANCE THAT IT OVERFLOWS, AND RENDERS 
THE START OF THE LINE AGAIN. THIS CAUSES MULTIPLE ISSUES, INVALID READS AND
UNEXPECTED CHARACTERS ON THE MINIMAP. THIS CAN BE FIXED 2 DIFFERENT WAYS:

THE FIRST IS BY REALLOCING EACH LINE BY THEIR LENGTH + (WIDTH - LENGTH), THEN
FILLING THEM WITH 0 UNTIL NULL IS REACHED, FOR EVERY LINE OF THE MAP.
THE SECOND ONE IS TO CHANGE THE RENDERING CONDITIONS, SO THAT RENDERING STOPS
WHEN NULL IS REACHED FOR EACH LINE, THIS HOWEVER LEAVES THE MINIMAP CUT.
FOR NOW THE SECOND SOLUTION IS USED, BUT RECONSIDER.

3. IF A CHAR BELONGING TO A TEXTURE IS FOUND (NO/SO/WE/EA) IN THE MAP, THE ERROR
OF MULTIPLE PLAYERS IS TRIGGERED INSTEAD OF THE ONE OF INVALID CHARS, THIS IS
FIXABLE BUT A MINOR ISSUE.
